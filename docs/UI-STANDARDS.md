# UI Standards

The UI foundation uses a dark enterprise shell with semantic tokens for primary, secondary, destructive, success, warning, muted, border, input, and ring states.

The current visual language emphasizes:

- High-contrast text
- Clear focus states
- Rounded surfaces
- Layered panels for shell and cards
- Responsive sidebar and content layout

Future component work should continue to rely on reusable primitives instead of page-specific styling.
